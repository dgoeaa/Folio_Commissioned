# DGO Digital Operations Platform Folio Journey

A self-contained, premium visual folio generated from the verified repository inventory.

## Open

Open `index.html` directly in any modern browser. No installation, server, package manager, external library, network call or build step is required.

## Included factual scope

- 8 registered platform surfaces and their repository-defined audiences, categories, exposure and ports
- 31 workspace routes and 5 navigation groups reflected in the source visual dataset
- Document lifecycle from intake through intelligence, orchestration, decision, dispatch and evidence
- Experience, orchestration, governance, security and data layers
- NITDA lockups, DGO visual language, responsive interaction and reduced-motion support

## Files

- `index.html` immersive journey
- `styles.css` complete responsive visual system
- `app.js` interactions, diagrams, motion and platform data
- `folio-data.json` repository-derived visual platform dataset
- `assets/` local brand and font assets
